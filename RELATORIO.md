Sobre o trabalho
O objetivo foi aprender, na prática, como publicar uma página web estática na internet usando o GitHub Pages. Para isso, desenvolvi um portfólio pessoal utilizando HTML e CSS, sem framework e sem JavaScript.
Escolhi o portfólio porque é um tema relacionado ao curso e permite apresentar minhas habilidades e projetos.

Como desenvolvi o site
Primeiro defini o conteúdo da página, com apresentação, habilidades, projetos e informações de contato. Depois organizei essas partes no index.html.
No HTML, criei as seções, inseri as imagens, títulos, textos e botões. Depois criei o style.css para definir cores, tamanhos, espaçamentos, bordas, sombras e efeitos.
Por fim, fiz testes e ajustes para verificar a organização da página e o funcionamento dos caminhos das imagens.
HTML e CSS

O HTML foi usado para criar a estrutura e o conteúdo da página. Utilizei elementos como header, section, títulos, parágrafos, imagens, div e footer.
A seção "Sobre Mim" possui uma foto e um texto de apresentação. Também criei cartões para as habilidades e dois projetos: uma padaria e uma loja virtual. No final, coloquei as informações de contato.
O CSS foi usado para estilizar a página. Escolhi tons de roxo e lilás e utilizei propriedades como display: flex, flex-wrap, gap, padding, margin, border-radius, box-shadow e object-fit.
Também utilizei :hover, transition e transform para criar efeitos nos cartões e botões.

O que é o GitHub Pages
Durante a pesquisa, aprendi que o GitHub Pages permite publicar sites diretamente a partir de um repositório do GitHub. Ele é adequado para páginas estáticas, como a desenvolvida neste trabalho.
Publicação do site
Depois de finalizar os arquivos, coloquei o projeto em um repositório público no GitHub e configurei a publicação pelo GitHub Pages.
Após a publicação, o site passou a ter um link público. Também verifiquei a organização dos arquivos e os caminhos das imagens.
Git e Markdown

Aprendi que o Git é um sistema de controle de versões usado para acompanhar alterações em projetos. Os commits registram mudanças e mantêm um histórico do desenvolvimento.
Também entendi que Git e GitHub não são a mesma coisa: Git é o sistema de controle de versões e GitHub é uma plataforma para armazenar e compartilhar repositórios.
Durante o trabalho também pesquisei sobre Markdown. Ele permite formatar textos de forma simples e é bastante utilizado no GitHub, inclusive em arquivos como README.md e RELATORIO.md.

.

Dificuldades e aprendizados
A parte que exigiu mais atenção foi entender como publicar os arquivos no GitHub Pages e organizar corretamente os caminhos das imagens.
Também aprendi mais sobre Git, GitHub, commits, Markdown e a relação entre HTML e CSS.
O trabalho mostrou como uma página criada com HTML e CSS pode sair do computador e ser publicada na internet.

Sobre Jekyll:
Jekyll é um gerador de sites estáticos que ajuda a criar páginas automaticamente. Diferente de HTML puro, ele utiliza modelos e uma estrutura própria para gerar as páginas.
Não utilizei Jekyll nem Hugo. O site foi desenvolvido diretamente com HTML e CSS, sem gerador, framework ou tema pronto.
